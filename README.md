# 大连，真是一次美妙的旅行 · DALIAN

在浏览器里播放的动效短片（不是 mp4）：用 [script-to-motion](https://github.com/kstost/script-to-motion) 制作，
HTML + CSS + SVG + GSAP 时间轴，逐帧对齐旁白时间轴。**在线观看：https://dogebi.github.io/DALIAN/**

打开根地址会根据屏幕自动选版本：**手机竖屏 → 9:16 竖版**，横屏或电脑 → 16:9 版。
也可以直接进：`/d/`（16:9 · 1920×1080，电脑／YouTube）· `/m/`（9:16 · 1080×1920，手机竖屏／Shorts）。

## 演出：把文字当图形来动

- **키네틱 타이포（字体作为图形）**：`时间` 用字形轮廓像水滴一样**融化**；`大连`、`上个世纪` 从自己的**笔画**中一片片飞回来**组合**；结尾标题由字符**聚集**成形；
  `星之海` 逐个**弹起**（pop），`大海` 像水面一样**起伏**（wave），`巴黎` 像霓虹招牌一样**点亮**（neon），`一百多年` 落下带**回弹与挤压**（drop + jelly），`时间` 与 `冬` 会**擦除→替换→翻转（3D）**。
  字形轮廓来自本项目已安装的 **SIL OFL 1.1** 字体（`scripts/text_to_paths.mjs` 生成，`js/glyphs.js`），因此每个笔画都是矢量、可无限放大。
- **其他视觉元素**：手绘地图／电车／街景（SVG 模块）、罗盘与时钟图标（描边绘制）、餐桌配料逐一**标注引线**、3D 投影地板网格与倾斜点阵（CSS 透视）、
  镜头光晕（flare）、雷达扫描线、火花／扭曲／汇聚粒子（Canvas + FXKit）、星空与水面反光（Canvas）、街景尘埃（Canvas）。
- **动画语言**：入场用模糊→清晰（blur-in），强调用缩放与字距呼吸，按键落点用 drop / jelly / pop，
  转场用地平线擦除（签名转场）、面板扫切、缩放穿越、光溢出；镜头有推、拉、平移、轻微手持与焦距感。
- **字体**：Noto Sans SC（正文／标题）、Noto Serif SC（衬线标题与字形轮廓）、Pretendard（数字／拉丁）、Space Grotesk（技术感数字与拉丁）、D2Coding（等宽标签）——**全部 SIL OFL 1.1**，许可文件随字体一起分发。

## 两个版本

| 路径 | 画幅 | 排布 |
|---|---|---|
| `/d/` | 16:9 · 1920×1080 | 左文右图、横向运镜、光比强 |
| `/m/` | 9:16 · 1080×1920 | 一屏一个念头，字在上图在下，正文压在 y 240–1440 内，让开平台 UI |

两版共用同一份 15 句文案、同一批画面模块（手绘辽东半岛地图／有轨电车／街景立面）和同一套视觉母题
——**那条不断变身的地平线**：海平线 → 海岸线 → 数字下的横线 → 电车轨道 → 檐口线 → 盘沿 → 划分夏冬的擦除线 → 航线 → 标题下划线。
但每一场的版式是**按各自画幅重新排的**，不是把 16:9 裁成竖屏。

## 怎么播放

页面渲染完成后**会自己播放**（在窗口内），不需要点击任何按钮。

- 想全屏看：按 `F` 或 `Enter`（浏览器规定全屏必须由按键触发）。
- 想带字幕看：按 `C`（本片没有音轨，字幕就是唯一的朗读轨）。
- 录制视频时用 `?noautoplay` 打开（例如 `/m/?noautoplay`）：会停在第 0 帧等你，按 Space（窗口内）或 Enter（全屏）开始。
- 快捷键：Space 播放/暂停 · ←/→ 0.5 秒（Shift 5 秒）· Shift+> / Shift+< 变速 · `C` 字幕 · `F` 全屏 · `R` 重播 · `D` 调试条。

## 结构

```
index.html            入口：按屏幕比例跳到 /d/ 或 /m/
d/                    16:9 版（index.html · css/ · js/ · fonts/ · audio/ · vendor/）
m/                    9:16 竖版（同上；版式在 m/css/style.css 与 m/js/scenes.js 里重新排）
  js/scenes.js        时间轴：所有动画都挂在 GSAP 主时间轴上，可拖动定位
  js/art/coast.js     手绘辽东半岛地图   art/tram.js 有轨电车   art/street.js 街景立面
  js/cues.js          由 tts.mjs 生成的句子时间
  fonts/              字体（SIL OFL 1.1）
  audio/narration.mp3 无声（没有旁白；给出 Fish Audio 音色 ID 与密钥即可配上中文配音）
```

页面在“无旁白”模式下运行：两版的 `index.html` 里都有一小段脚本把音轨标记为空，于是播放由时间轴自己的时钟驱动，
既不需要等 mp3，也不会碰到浏览器的音频自动播放限制。加上真实配音后删掉那段即可恢复同步播放。

## 原创性与许可

- 画面里的地图、电车、街景、海味、图标、图形与文案全部为本片在代码里绘制／撰写，没有使用任何网络素材、
  图标集、图片或模板；没有用户提供的外部素材。
- 字体：**SIL OFL 1.1** — Noto Sans SC（正文／标题）、Noto Serif SC（衬线标题）、Pretendard（数字／拉丁）、
  D2Coding（等宽标签）。许可文件随字体一起放在各自的 `fonts/` 中。
- GSAP 3.15.0 按 GSAP 标准「免费使用」许可原样分发，`vendor/gsap/` 内附许可声明。

## 校验

两版都跑过 `check` / `smoke` / `check_fonts` / `snapshot`（真实 Chromium 截图）／`--safezone`（9:16 安全区）／
`--seekcheck`（可重复性）／`--perf`：帧内无文字重叠与裁切、竖版正文全部落在安全区内、逐帧可重复（确定性）、
播放开销 p95 ≈ 0.2 ms。
